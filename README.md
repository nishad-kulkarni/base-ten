# Base10

Base10 is a nonprofit educational initiative dedicated to teaching foundational mathematics and technology concepts to underprivileged students in rural Maharashtra, India. The platform provides free, structured lessons through recorded lectures, allowing students to develop problem-solving skills and digital literacy regardless of location or financial background.

## Mission

Many students have limited access to technology education and advanced mathematics outside of their standard curriculum. Base10 aims to bridge that gap by providing free educational resources focused on practical mathematical reasoning and introductory computer science.

## Features

- Structured mathematics curriculum
- Mental math and problem-solving techniques
- Technology lessons including:
  - Google Docs
  - Google Slides
  - Google Sheets
  - Python
  - Java
  - AP Computer Science Principles concepts
  - AP Computer Science A concepts
- Recorded video lectures
- Mobile-friendly responsive website
- Low-bandwidth design for accessibility
